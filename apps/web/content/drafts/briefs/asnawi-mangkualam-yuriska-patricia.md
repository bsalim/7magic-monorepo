# Research brief: Asnawi Mangkualam & Yuriska Patricia

Compiled 2026-10-07 (Wednesday). Status: **wedding not yet held.** No date, venue or
adat for the wedding has been announced as of this brief. This is background only;
the article is completed on the wedding day.

Rule used throughout: a fact is listed in the main sections only if at least two
independent outlets (or one outlet plus the couple's own post as quoted) carry it.
Outlets from the same media group are counted as ONE source:

- detik network = detikHOT, Wolipop, detikInet, Haibunda
- IDN Media = IDN Times, Popbela, Popmama
- KLY (Kapanlagi Youniverse) = KapanLagi, Liputan6, Brilio, Fimela
- MNC = iNews, Okezone (both republished on RCTI+)
- Jawa Pos = JawaPos.com, Prokalteng
- VIVA, Nyata Media, Wartabanjar and Kompas are each counted as their own group (added by the fact-check)

Instagram itself could not be read (it blocks unauthenticated access), so every
caption below is as quoted by outlets. The fact-checker should open the couple's
posts directly and confirm captions and post dates.

All day-of-week checks were run with Python `datetime`; mismatches are listed under
Conflicts.

**Yuriska Patricia**
- Born 23 November 2000 in Bandung, West Java. [S16][S22][S24][S28][S50] Wikipedia gives the same date. [S43]
